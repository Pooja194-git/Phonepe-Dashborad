
# 📊 PhonePe Transaction Analysis Dashboard

## 📌 Short Description

An interactive **Power BI dashboard** developed to analyze PhonePe transaction data across multiple financial services. The project provides a consolidated view of transaction performance, payment status, transaction amounts, and service-level trends through interactive visualizations and filters.

## 🛠️ Tech Stack

* **Power BI** – Dashboard development and data visualization
* **Power Query** – Data cleaning and transformation
* **Data Modeling** – Relationships between datasets and reporting structure

## 📂 Data Source

The project uses a **PhonePe transaction dataset** containing transaction, user, service, payment-status, and date-related information.

The data covers multiple service categories:

* Insurance
* Loans
* Money Transfer
* Recharge & Bills

> **Note:** The dataset used for this project is for educational/portfolio purposes and is not official proprietary PhonePe data.

## ✨ Features

* 📈 Interactive transaction analysis
* 💰 Transaction amount analysis
* ✅ Payment status analysis
* 🏦 Service-wise transaction breakdown
* 📅 Date-based transaction filtering
* 👥 User and transaction-level analysis
* 📊 KPI cards for quick performance monitoring
* 🔎 Interactive slicers and filters
* 🧭 Page navigation between dashboard sections
* 📱 Dedicated reporting pages for different services

## 🌟 Highlights

* Developed a **5-page interactive Power BI dashboard** covering:

  * Home
  * Insurance
  * Loans
  * Money Transfer
  * Recharge & Bills
* Designed an intuitive dashboard layout for easy navigation and analysis.
* Used visualizations and KPIs to identify transaction trends and service-level performance.
* Applied data transformation and modeling techniques to prepare the dataset for analysis.
* Created interactive filters to allow users to explore transaction performance across different periods and service categories.
* Focused on presenting data in a **business-friendly and decision-oriented format**.

## 🎯 Project Objective

The primary objective of this project is to transform raw transaction data into an interactive analytical dashboard that enables users to **monitor transaction performance, compare service categories, identify trends, and derive actionable business insights**.
